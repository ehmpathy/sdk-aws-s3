# 2.1 blackbox criteria — conditional writes for sdkAwsS3

> wish: fulfill [ehmpathy/sdk-aws-s3#5](https://github.com/ehmpathy/sdk-aws-s3/issues/5)
> vision: `1.vision.yield.md` — put-if-absent, compare-and-set, compare-and-delete, opt-in etag

these are experience boundaries only — what a consumer supplies and what they receive back.
no mechanism (headers, aws commands, error-lib classes) is named here.

---

# usecase.1 = distributed lock — acquire only if unheld

given('the lock object is absent')
  when('a consumer writes with condition.etag = null (assert-absent) and asks for meta')
    then('the write succeeds')
      sothat('the consumer holds the lock')
    then('a meta.etag is returned as a non-empty string')
      sothat('the consumer holds a fence token to release safely later')

given('the lock object is present')
  when('a consumer writes with condition.etag = null (assert-absent)')
    then('the write is rejected with a typed precondition-failed error')
      sothat('the consumer learns someone else holds the lock, in one atomic call, without a re-read')
    then('the prior object is left unchanged')
      sothat('the current holder is never clobbered by a losing acquirer')

---

# usecase.2 = optimistic concurrency — write only if unchanged since read

given('an object is present and the consumer read its current etag')
  when('the consumer writes with condition.etag set to that etag and the etag still matches')
    then('the write-back succeeds and the new body replaces the old')
      sothat('a read-modify-write completes safely when no one raced')

given('an object is present but was changed after the consumer read it')
  when('the consumer writes with condition.etag set to the now-stale etag')
    then('the write is rejected with a typed precondition-failed error')
      sothat('the consumer detects the concurrent edit instead of a silent overwrite')
    then('the object still holds the body written by the concurrent writer')
      sothat('the intervening write is preserved')

---

# usecase.3 = fenced release — delete only our own hold

given('an object is present and the consumer holds its etag as a fence token')
  when('the consumer deletes with condition.etag set to that matching etag')
    then('the object is removed')
      sothat('the lock is released')

given('an object is present but its etag differs from the fence token the consumer holds')
  when('the consumer deletes with condition.etag set to the stale token')
    then('the delete is rejected with a typed precondition-failed error')
      sothat('a lock that expired and was re-acquired by someone else is never deleted')
    then('the object is left untouched')
      sothat('the new holder keeps their lock')

given('no object is present at the key')
  when('the consumer deletes with condition.etag set to any value')
    then('the delete is rejected with a typed precondition-failed error')
      sothat('the consumer catches one typed error for "my fenced write did not happen", whether the object is stale or absent')

---

# usecase.4 = read the etag receipt — opt-in meta on read

given('an object is present')
  when('the consumer reads with include.meta requested')
    then('the consumer receives an envelope of the body plus a meta.etag')
      sothat('the consumer can fence a later write-back or release with the returned etag')
    then('the returned etag, passed back verbatim into a later condition.etag, is accepted')
      sothat('the etag round-trips as an opaque token with no reshaping required')

given('no object is present')
  when('the consumer reads with include.meta requested')
    then('the consumer receives an absent result (null), not an envelope')
      sothat('the absent case is unambiguous even when meta was requested')

---

# usecase.5 = backwards-compatible defaults — no meta requested

given('any prior caller that does not request meta')
  when('the consumer reads without include')
    then('the consumer receives the plain body string, or an absent result when the object is absent')
      sothat('every read authored before this change keeps working byte-for-byte')

given('any prior caller that does not request meta')
  when('the consumer writes without include and without condition')
    then('the write returns no value and applies last-writer-wins')
      sothat('every unconditional write authored before this change keeps working')

given('any prior caller')
  when('the consumer omits condition entirely on write or delete')
    then('the operation is unconditional — it neither asserts absence nor asserts an etag')
      sothat('the common get/set/del path carries zero conditional-write friction')

---

# usecase.6 = typed, actionable failure surface

given('any conditional operation that fails its precondition')
  when('the consumer catches the thrown error')
    then('the error is a single typed precondition-failed error type, catchable by instanceof')
      sothat('the consumer branches on a type, not on a brittle status-string match')
    then('the error message names the object and states how to recover')
      sothat('a human reading the failure knows to re-read the latest etag and retry')

given('a conditional operation that fails for a reason other than a precondition (e.g. an unexpected service fault)')
  when('the consumer catches the error')
    then('the error is not misreported as a precondition failure')
      sothat('the consumer does not treat an infrastructure fault as a lost race')
