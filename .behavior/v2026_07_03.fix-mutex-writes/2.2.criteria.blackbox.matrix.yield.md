# 2.2 blackbox criteria — coverage matrix

> distilled from `2.1.criteria.blackbox.yield.md`

the conditional-write surface has two operation families: **writes** (`set`, `del`) driven by a
`condition`, and **reads** (`get.one`) shaped by `include`. two matrices below, one per family,
plus a small error-surface matrix.

---

## matrix A — conditional writes (`set` / `del`)

the independent variables that fully determine a conditional-write outcome:

- **op** — `set` vs `del` (the only two write ops that accept a `condition`)
- **condition** — omitted · `{ etag: null }` (assert-absent) · `{ etag: <match> }` (assert-current) · `{ etag: <stale> }` (assert-wrong-version)
- **object state** — absent vs present at the key

| ind: op | ind: condition | ind: object state | dep: outcome | dep: object after | dep: usecase |
|---------|----------------|-------------------|--------------|-------------------|--------------|
| set | omitted | absent | succeeds (last-writer-wins) | body written | uc5 |
| set | omitted | present | succeeds (last-writer-wins) | body overwritten | uc5 |
| set | `{ etag: null }` | absent | succeeds | body written | uc1 |
| set | `{ etag: null }` | present | typed precondition-failed error | prior body unchanged | uc1 |
| set | `{ etag: match }` | present | succeeds | new body replaces old | uc2 |
| set | `{ etag: stale }` | present | typed precondition-failed error | concurrent body preserved | uc2 |
| del | omitted | absent | succeeds (idempotent no-op) | remains absent | uc5 |
| del | omitted | present | succeeds | removed | uc5 |
| del | `{ etag: match }` | present | succeeds | removed | uc3 |
| del | `{ etag: stale }` | present | typed precondition-failed error | object untouched | uc3 |
| del | `{ etag: any }` | absent | typed precondition-failed error | remains absent | uc3 |

### gaps & unrepresentable rows (flagged)

- **`set` `{ etag: match }` on absent** — not reachable: to hold a match etag the object must be
  present. omitted by construction.
- **`del` `{ etag: null }`** — **unrepresentable** by type: `del`'s condition is `{ etag: string }`
  (no `null`). s3 has no delete-if-absent, so the type forbids the row.
- **conflicted conditions (both assert-absent and assert-etag)** — **unrepresentable**: a single
  `etag` field cannot clash with itself. no row exists to test.
- symmetry check: every (op × condition × state) combination that the type system permits has a
  specified outcome above. no permitted row is absent.

---

## matrix B — reads (`get.one`)

independent variables:

- **include** — omitted vs `{ meta: true }`
- **object state** — absent vs present

| ind: include | ind: object state | dep: return shape | dep: usecase |
|--------------|-------------------|-------------------|--------------|
| omitted | present | plain body string | uc5 |
| omitted | absent | absent result (null) | uc5 |
| `{ meta: true }` | present | envelope `{ body, meta: { etag } }` | uc4 |
| `{ meta: true }` | absent | absent result (null), not an envelope | uc4 |

### invariant row (round-trip)

| ind: source of etag | ind: reused as | dep: outcome | dep: usecase |
|---------------------|----------------|--------------|--------------|
| `get.one` meta.etag (present object) | `set`/`del` `condition.etag` | accepted verbatim, no reshape | uc4 |

symmetry check: both `include` values × both object states are enumerated. no gap.

---

## matrix C — error surface (typed failure)

independent variable: the failure kind.

| ind: failure kind | dep: error type surfaced | dep: sothat | dep: usecase |
|-------------------|--------------------------|-------------|--------------|
| precondition unmet (assert-absent on present, stale etag, or fenced-delete on absent) | single typed precondition-failed error, instanceof-catchable, message names object + recovery | consumer branches on type, not status string | uc6 |
| non-precondition service fault | NOT reported as precondition-failed | consumer does not treat infra fault as a lost race | uc6 |

symmetry check: the two mutually-exclusive failure kinds each have a specified surface. no gap.

---

## decomposition assessment

matrix A carries 3 independent dimensions (op, condition, object state); B carries 2; C carries 1.
none reaches the 4+ dimension explosion threshold. the write family and read family are cleanly
separable (they share no independent variable), and each matrix enumerates fully within reason. no
decomposition into narrower boundaries is warranted — the conditional-write behavior is already a
tight, recomposable scope.
